# TextBeacon

看板と空色ガラスで「入ったらメッセージが出るエリア」を作るプラグインです。

## 内容

- 看板を設置してBeaconエリアを作成
- エリア侵入時にメッセージ通知
- `/tb on` / `/tb off` で受信切り替え
- `&` と `&#RRGGBB` のカラーコード対応

## 使い方

1. `/tb <メッセージ>` で内容入り看板を受け取る
2. その看板を空色ガラスの近く（半径5ブロック以内）に設置する
3. ガラスが5x5x5を超えていなければそこにBeaconが作成される

ガラスは消えるため、保護されたガラスが1つでも含まれているとBeaconは作成されません。

## opコマンド

- `/tb list`
- `/tb remove <uuid>` など

## 権限

| 権限 | 既定 | 内容 |
|---|---|---|
| `textbeacon.use` | true | メッセージを受け取る |
| `textbeacon.create` | op | Beaconを作成する (建築権限のあるグループに付与します) |
| `textbeacon.remove` | op | 他の人のBeaconを削除する |
| `textbeacon.admin` | op | 管理コマンドを使う |

## 保護プラグイン等との併用について

Beacon 作成時、ガラスを消す前に、そのプレイヤーが各ガラスを破壊してよいかをサーバー全体へ確認します。この確認は、ガラス1つにつき1回、通常のブロック破壊イベント（BlockBreakEvent）を発生させる方式です。1つでもキャンセルされれば、どのガラスも消さず Beacon は作成されません。

この方式のため、破壊イベントを受けてキャンセル以外の処理を行うプラグインとは、次の相互作用が起こります。

- 破壊の記録・集計（ブロック破壊のログ、統計、実績や報酬の付与など）を行うプラグイン: 実際には壊れていないガラスについても、確認イベントの分だけ記録・集計されることがあります。併用は可能ですが、その前提でログや統計を解釈してください。
- 保護領域への破壊試行を運営へ通知するプラグイン: 保護されたガラスを含む作成操作のたびに、破壊試行として通知されることがあります。
- 領域保護のように、破壊不可の場所でイベントをキャンセルするだけのプラグイン: 保護の判定はそのまま機能し、問題ありません。

上記の記録・通知を避けたい構成では、破壊イベントに副作用のあるプラグインとの併用は推奨しません。
