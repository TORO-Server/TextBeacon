# TextBeacon

看板と空色ガラスで「入ったらメッセージが出るエリア」を作るプラグインです。

## 内容

- 看板を設置してBeaconエリアを作成
- エリア侵入時にメッセージ通知
- `/tb on` / `/tb off` で受信切り替え
- `&` と `&#RRGGBB` のカラーコード対応

## 使い方

1. `/tb <メッセージ>` で内容入り看板を受け取る
2. その看板を空色ガラスの近く（半径5ブロック以内）に設置する
3. ガラスが5x5x5を超えていなければそこにBeaconが作成される

## opコマンド

- `/tb list`
- `/tb remove <uuid>` など
